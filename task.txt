必须修改的问题
=======

1. 修复 full EKF covariance update（最重要）

当前代码：

K = P_pose @ J.T @ inv(S)

只使用：

P[:6,:6]

这是错误的。

导致：

* velocity covariance 从未被 measurement 更新
* pose-velocity correlation 完全失效
* velocity state 不是 EKF 真正状态

必须改成：

完整 measurement Jacobian：

H.shape = (2N, 12)

其中：

H[:, :6] = pose Jacobian
H[:, 6:] = 0

然后：

S = H @ P @ H.T + R

K = P @ H.T @ inv(S)

delta = K @ innovation

更新完整状态：

state += delta

然后：

P = (I-KH)P(I-KH)^T + KRK^T

必须删除：

* P_pose
* partial covariance update
* _expand_K hack

========================

2. 修复 rotation update（SO(3) manifold consistency）

当前代码：

self.state[:3] += delta[:3]

这是错误的。

rotation 不属于欧氏空间。

predict 已经使用：

R_pred = R @ Exp(omega * dt)

但 update 仍然是 vector addition。

必须改成：

R_old =
Rotation.from_rotvec(state[:3])

R_delta =
Rotation.from_rotvec(delta[:3])

R_new = R_old * R_delta

state[:3] = R_new.as_rotvec()

translation update 保持：

t += delta_t

velocity update 可以继续使用欧氏加法。

========================

3. 修复 velocity estimation feedback contamination

当前逻辑：

保存 predict 前 pose：

prev_pose

然后：

predict
update

最后：

velocity =
current_pose - prev_pose

这是错误的。

因为 velocity estimation 包含：

* predict motion
* update correction

会导致：

* velocity 自我强化
* positive feedback
* drift accumulation

必须改成：

velocity estimation 基于：

“连续两个 posterior pose”

即：

保存：
last_posterior_pose

update 完成后：

velocity =
posterior(k) - posterior(k-1)

不要使用 predict 前 pose。

========================

4. 修复 Q 非对称问题

当前代码：

Q[:3,6:9] 有值
但：
Q[6:9,:3] 没有对应转置

导致：
Q 非对称。

协方差矩阵必须：

symmetric positive semi-definite。

必须增加：

Q[6:9,:3] = Q[:3,6:9].T
Q[9:12,3:6] = Q[3:6,9:12].T

最终：

assert np.allclose(Q, Q.T)

========================

5. 使用 OpenCV analytic Jacobian

当前代码：

compute_reprojection_jacobian()

使用 numerical differentiation：

eps finite difference。

虽然理论正确，但：

* 慢
* epsilon sensitive
* SO(3)局部不稳定
* planar degeneracy 时数值容易恶化

必须改成：

使用：

cv2.projectPoints(..., jacobian=True)

提取：

* rvec Jacobian
* tvec Jacobian

构造：

J_pose.shape = (2N,6)

不要再手工数值微分。

========================

6. 修复 Mahalanobis threshold DOF 问题

当前：

threshold=9.21

对应：
chi-square with 2 DOF。

但 innovation 实际维度：

2N

例如：
7 points -> 14 DOF

必须：

threshold 根据 measurement dimension 自动计算。

推荐：

from scipy.stats import chi2

threshold =
chi2.ppf(confidence_level, dof)

其中：

dof = 2 * N

推荐：

confidence_level = 0.99

========================

7. 修复 covariance numerical stability

当前：

直接：

np.linalg.inv(S)

必须：

优先：

scipy.linalg.cho_factor
scipy.linalg.cho_solve

若失败：
使用 pinv。

减少：

* 数值不稳定
* planar degeneracy 时崩溃

========================

8. velocity damping 位置修正

当前：

先 predict
后 damping

更合理方式：

predict 前：

omega *= damping
v *= damping

然后：

再做 prediction。

因为 damping 本质是：
velocity decay prior。
