请基于当前版本的 StaticPoseOptimizer 增加：

“per-point reprojection uncertainty weighting”

目标：

不同插座孔位由于尺寸不同，
圆心检测精度不同。

小孔：

* edge pixel 更少
* 亚像素定位更不稳定
* ellipse fitting 更敏感

因此：

不同点应具有不同 reprojection uncertainty。

希望：

在 bundle adjustment 中：

对不同点赋不同权重。

========================
当前实现
====

当前 residual：

residuals.extend(
(proj - pts2d).flatten()
)

这等价于：

所有点：

* 相同 covariance
* 相同 confidence
* isotropic pixel noise

即：

Σ_i = I

========================
目标修改
====

增加：

per-point sigma weighting。

优化目标：

Σ ||r_i / sigma_i||²

即：

sigma 越大：
该点权重越低。

sigma 越小：
该点权重越高。

========================
要求
==

1. point_sigmas 手动配置

不要自动估计。

在 optimizer 初始化时：

允许用户手动配置：

self.point_sigmas

例如：

self.point_sigmas = np.array([
0.3,
0.3,
0.5,
1.0,
1.2,
...
], dtype=np.float64)

其中：

每个元素对应：
一个 3D 点 / 孔位。

单位：
pixel standard deviation。

========================

2. residual whitening

当前：

err = proj - pts2d

改成：

err[:,0] /= point_sigmas
err[:,1] /= point_sigmas

即：

u/v 方向共享同一个 sigma。

默认：

每个点：
仍然是 isotropic covariance：

Σ_i = sigma_i² * I

========================

3. 保持 perturbation prior residual

继续保留：

r_prior =
delta / prior_sigma

不要删除。

最终 residual：

[
weighted reprojection residual,
prior residual
]

========================

4. 增加 sanity check

检查：

# len(point_sigmas)

pts3d.shape[0]

若不一致：

抛出明确异常。

========================

5. 增加默认配置

若用户未提供：

默认：

所有点 sigma=1.0

即：

self.point_sigmas =
np.ones(num_points)

========================

6. 增加调试输出

输出：

* 每个点 sigma
* weighted reprojection RMS
* unweighted reprojection RMS

方便分析：
权重是否合理。

========================

7. 不要修改以下逻辑

保持：

* global bMo optimization
* per-frame perturbation
* SE(3) perturbation
* robust loss
* anisotropic perturbation prior

不变。

========================

8. 代码要求

* 使用 numpy vectorized operations
* 不要逐元素 append
* 保持代码清晰
* 增加必要注释

========================

9. 最终目标

得到一个：

* weighted reprojection bundle adjustment
* per-point confidence modeling
* robust static pose optimizer

其中：

大孔位：
高权重。

小孔位：
低权重。

从而：

减少 noisy small-hole detections
对整体 bMo 的污染。
